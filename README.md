# ITGirl School - Frontend Mentor Repository

Репозиторий преподавателя фронтенд-разработки, содержащий примеры кода и учебные материалы по различным темам веб-разработки.

## 📚 Структура репозитория

### HTML Уроки (Lesson Files)
Интерактивные HTML файлы с примерами и объяснениями:

- **Основы HTML** -
  - Атрибуты тегов, структура документа, основные элементы

- **CSS & Layout** -
  - БЭМ методология, SASS препроцессор, CSS Grid, Flexbox, Float, Позиционирование

- **JavaScript** -
  - **Типы данных и основы:** Типы данных, переменные
  - **Логика и циклы:** Условные операторы (if-else, switch), циклы
  - **Функции и ООП:** Функции, объекты, прототипы, контекст `this`
  - **Продвинутые концепции:** Асинхронный код (async/await), обработка ошибок, модули, TypeScript
  - **Практика:** Работа с массивами, событиями (`event.target`), коллекциями, формами, запросы (fetch), cookies

- **Специальные материалы:**
  - `faq2.html`, `faq3.html`, `faq5.html` - Часто задаваемые вопросы
  - `lesson20-relax.html` - Материал для отдыха 😊
  - `form.php` - Пример работы с PHP формами
  - `lesson22-forms-valid-requests.html` - Валидация форм и HTTP запросы

### JavaScript файлы (`/js`)
Примеры кода и вспомогательные скрипты:
- `script.js`, `script-test.js` - Основные примеры
- `date.js` - Работа с датами
- `iife.js` - IIFE (Immediately Invoked Function Expression)
- `module1.js`, `module2.js` - Примеры модульности
- `oop-context.js` - Примеры ООП и контекста
- `node.js` - Примеры для Node.js
- `typescript.ts` - TypeScript примеры

### SASS/SCSS (`/sass`)
Препроцессор примеры:
- `input.scss` - Основной файл
- `_part.scss` - Пример модульности
- `reset.scss` - CSS reset

### CSS Стили (`/style`)
Скомпилированные стили и готовые решения:
- `style.css`, `output.css` - Основные стили
- `normalize.css` - Нормализация CSS

### Дополнительно
- `/phpmailer` - PHPMailer для отправки писем

## 🎓 Темы покрытия

✅ HTML5 и семантика
✅ CSS3, SASS, BEM, CSS Grid, Flexbox
✅ JavaScript (ES6+, асинхронный код)
✅ ООП и функциональное программирование
✅ TypeScript
✅ DOM манипуляция и события
✅ Fetch API и HTTP запросы
✅ Формы и валидация
✅ Алгоритмы и структуры данных

## 📝 Использование

Файлы можно открыть непосредственно в браузере или использовать как справочный материал при обучении веб-разработке.
